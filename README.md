# Windows Launchpad

Нативный полноэкранный Launchpad для Windows 10/11, повторяющий интерфейс и
анимации классического Launchpad из macOS.

## Возможности

- страницы приложений с плавным свайпом;
- папки, перетаскивание и ручная сортировка;
- нечёткий поиск с поддержкой русского и английского языка;
- удаление ярлыков через режим покачивания;
- качественные системные иконки без повторной загрузки;
- поддержка экранов с высокой герцовкой и масштабированием;
- запуск без прав администратора.

## Установка

Для сборки нужны Visual Studio 2022, компонент **Desktop development with C++**
и Windows SDK.

Откройте PowerShell в папке проекта и выполните:

```powershell
cmake --preset vs2022-x64
cmake --build --preset vs2022-x64-release --parallel
ctest --test-dir .\out\build\vs2022-x64 -C Release --output-on-failure

Set-ExecutionPolicy -Scope Process Bypass
.\scripts\install-launchpad.ps1
```

Launchpad появится в меню «Пуск». Оттуда его можно закрепить на панели задач.
Установка выполняется только для текущего пользователя и не требует прав
администратора.

## Добавление приложений

Добавляйте ярлыки `.lnk`, а не сами файлы `.exe`.

1. Откройте Launchpad и нажмите `Ctrl+O`.
2. Скопируйте ярлык приложения в открывшуюся папку `Applications`.
3. Вернитесь в Launchpad и нажмите `F5`.

На клавиатуре Mac через Parallels используйте `fn+F5`. Ярлык также можно
перетащить из Проводника прямо на нужное место в Launchpad.

## Управление

| Действие | Управление |
|---|---|
| Запустить приложение | клик по иконке |
| Найти приложение | клик по строке поиска и ввод текста |
| Выделить весь запрос | `Ctrl+A` |
| Очистить поиск | `Esc` |
| Переключить страницу | свайп ЛКМ, колесо или `Page Up/Down` |
| Переместить приложение | удерживать и перетащить |
| Создать папку | перетащить приложение на другое |
| Добавить приложение в папку | перетащить его на папку |
| Переименовать папку | открыть папку и нажать на её название |
| Удалить ярлык | удерживать иконку и нажать крестик |
| Обновить список | `F5` |
| Открыть папку `Applications` | `Ctrl+O` |
| Показать или скрыть Launchpad | `Win+Alt+Space` |

Удаление из Launchpad отправляет в Корзину только ярлык. Установленная программа
остаётся на компьютере.

## Удаление Launchpad

```powershell
& "$env:LOCALAPPDATA\Programs\Windows Launchpad\uninstall-launchpad.ps1"
```

Чтобы также удалить пользовательскую раскладку и ярлыки, добавьте
`-RemoveUserData`.
