# Windows Launchpad

Нативный полноэкранный лаунчер для Windows 10/11 в стиле классического macOS
Launchpad. Он читает приложения из управляемой папки `Applications/`, показывает
системные иконки, фильтрует список по мере ввода и запускает выбранный ярлык.

## Что уже работает

- адаптивная сетка 7 × 5, несколько страниц и их постоянные границы;
- настоящие обои под сильным blur, тёмным tint и Windows Desktop Acrylic;
- реальные `.lnk`, `.url`, `.appref-ms` и `.exe` только из `Applications/`;
- DPI-зависимые Shell-иконки от 256 px с Direct2D-кэшем и fallback-плитки;
- предварительная загрузка всех иконок до первого видимого кадра;
- Unicode-поиск, включая кириллицу;
- drag-and-drop, режим покачивания, ручная сортировка и Launchpad-папки;
- перенос на соседнюю или новую страницу удержанием у края экрана;
- перестановка приложений внутри открытой папки;
- вытаскивание приложения из открытой папки на корневую сетку и страницы;
- отдельный заголовок папки и адаптивная матовая панель по числу рядов;
- крестик удаления в режиме покачивания с перемещением объекта в Корзину;
- drag-and-drop поддерживаемого ярлыка из Проводника или Корзины прямо на
  текущую страницу с автоматическим обновлением;
- постоянная раскладка в `LaunchpadLayout.store`;
- мышь, колесо, стрелки, `Page Up/Down`, `Home/End`, `Enter`, `Esc`;
- свайп ЛКМ по пустому фону, горизонтальный жест тачпада и закрытие кликом;
- Per-Monitor DPI Awareness v2 и уважение системной настройки анимаций;
- постоянно прогретый процесс, один экземпляр и клавиша `Win+Alt+Space`;
- частота кадров подстраивается под активный монитор, включая 120 Гц;
- оригинальная многоразмерная иконка Launchpad внутри `Launchpad.exe`;
- стабильный AppUserModelID и ярлыки меню «Пуск»/рабочего стола для закрепления;
- пользовательский автозапуск без прав администратора.

## Папка Applications

Launchpad показывает только файлы из:

```text
C:\macos_folder\macOS\Applications
```

Добавляйте и удаляйте в ней ярлыки, не затрагивая установленные программы.
Поддерживаются подпапки. В открытом Launchpad:

- `F5` — перечитать каталог;
- `Ctrl+O` — открыть каталог в Проводнике.

Чтобы импортировать существующие Windows-ярлыки:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\sync-applications.ps1
```

Импорт не копирует сами программы, а только маленькие ярлыки. Приложения macOS,
которые Parallels публикует в Start Menu, SDK-команды, документация,
деинсталляторы, административные и вспомогательные системные средства
автоматически исключаются.
Для однократной очистки результата старого широкого импорта:

```powershell
.\scripts\sync-applications.ps1 -CleanPreviousStartMenuImports
```

## Требования

- Windows 10 версии 1903 или новее / Windows 11;
- Visual Studio 2022 с workload **Desktop development with C++**;
- компоненты **C++ CMake tools for Windows** и Windows 10/11 SDK;
- CMake 3.23+ (версия из Visual Studio подходит);
- архитектура x64.

Сторонних runtime-зависимостей нет. `vcpkg.json` намеренно содержит пустой
список: это валидный manifest и фиксированная точка для будущих зависимостей.

## Установка как обычного приложения

После Release-сборки запустите:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\install-launchpad.ps1
```

Или дважды нажмите `scripts\install-launchpad.cmd`. Установка не требует прав
администратора и выполняется в:

```text
%LOCALAPPDATA%\Programs\Windows Launchpad
```

При первой установке существующие `Applications/` и
`LaunchpadLayout.store` переносятся туда без изменения раскладки. Создаётся
ярлык `Launchpad` в меню «Пуск», включается пользовательский автозапуск
`--background`, затем прогретый процесс запускается в фоне. Для дополнительного
ярлыка на рабочем столе передайте установщику `-DesktopShortcut`.

Чтобы закрепить Launchpad: откройте **Пуск → Все приложения**, нажмите правой
кнопкой по **Launchpad** и выберите **Закрепить на панели задач**. Не закрепляйте
`Launchpad.exe` прямо из `out\build`: путь сборки непостоянный.

Удаление приложения с сохранением раскладки и каталога:

```powershell
& "$env:LOCALAPPDATA\Programs\Windows Launchpad\uninstall-launchpad.ps1"
```

Для полного удаления пользовательских данных добавьте `-RemoveUserData`.

## Сборка в Visual Studio 2022

1. Откройте Visual Studio.
2. Выберите **File → Open → Folder**.
3. Укажите `C:\macos_folder\macOS`.
4. Дождитесь завершения CMake configure.
5. Выберите preset `vs2022-x64`, конфигурацию `Release`.
6. В **Select Startup Item** выберите `Launchpad.exe`.
7. Выполните **Build → Build All**.
8. Нажмите `F5` или **Debug → Start Without Debugging**.

Visual Studio использует корневые `CMakeLists.txt` и `CMakePresets.json`;
создавать `.sln` вручную не требуется.

## Сборка из Developer PowerShell

```powershell
cd C:\macos_folder\macOS
cmake --preset vs2022-x64
cmake --build --preset vs2022-x64-release --parallel
ctest --test-dir .\out\build\vs2022-x64 -C Release --output-on-failure
```

Готовый файл:

```text
C:\macos_folder\macOS\out\build\vs2022-x64\Release\Launchpad.exe
```

Debug-сборка:

```powershell
cmake --build --preset vs2022-x64-debug --parallel
ctest --test-dir .\out\build\vs2022-x64 -C Debug --output-on-failure
```

## vcpkg

Сейчас библиотек из vcpkg нет: Direct2D, DirectWrite, WIC и Shell API входят в
Windows SDK. Если Visual Studio уже настроена на manifest mode, дополнительных
действий не требуется. Для явного toolchain:

```powershell
cmake --preset vs2022-x64 `
  -DCMAKE_TOOLCHAIN_FILE="$env:VCPKG_ROOT\scripts\buildsystems\vcpkg.cmake"
```

## Запуск и управление

Обычный запуск:

```powershell
.\out\build\vs2022-x64\Release\Launchpad.exe
```

Начинайте печатать сразу — отдельный клик по поиску не нужен.

| Действие | Управление |
|---|---|
| Выбрать приложение | мышь или стрелки |
| Запустить | клик или `Enter` |
| Переместить иконку | удерживать около 0,34 с и перетащить |
| Перенести на другую/новую страницу | во время перетаскивания удерживать иконку у левого/правого края около 0,48 с |
| Создать папку | перетащить приложение в центр другого приложения |
| Добавить в папку | перетащить приложение в центр существующей папки |
| Изменить порядок внутри папки | открыть папку, удерживать и перетащить приложение |
| Вынести из папки | удерживать приложение и вывести курсор за границу панели; затем отпустить на сетке или странице |
| Вернуть из Корзины | перетащить удалённый ярлык из системной Корзины на нужную страницу Launchpad |
| Удалить из Launchpad | удерживать иконку, затем нажать крестик справа сверху и подтвердить |
| Открыть/закрыть папку | клик по папке / `Esc` или клик вне неё |
| Переименовать папку | клик по её заголовку или `F2`, затем `Enter` |
| Следующая/предыдущая страница | свайп ЛКМ по пустому фону, колесо/тачпад, точки, `Ctrl+←/→` или `Page Down/Page Up` |
| Закрыть/скрыть | клик по пустому месту или `Esc` |
| Первый/последний результат | `Home` / `End` |
| Перечитать `Applications/` | `F5` |
| Открыть `Applications/` | `Ctrl+O` |
| Стереть символ | `Backspace` |
| Очистить поиск / закрыть | `Esc` / повторный `Esc` |

По умолчанию закрытие скрывает окно, но оставляет иконки в памяти. Поэтому
следующее открытие не перечитывает их из Shell и появляется без pop-in.

Подтверждение удаления показывается прямо поверх Launchpad в его тёмном
интерфейсе; системное белое окно и права администратора для этого не нужны.
Крестик работает только с объектами внутри управляемой папки `Applications/`.
Для ярлыка в Корзину отправляется сам ярлык, а установленная программа не
деинсталлируется. Если в `Applications/` лежит `.exe`, в Корзину отправляется
именно этот исполняемый файл. Для восстановления перетащите объект из
системной Корзины прямо на Launchpad: Windows Shell вернёт его в
`Applications/`, Launchpad автоматически перечитает каталог и постарается
поставить иконку на открытую страницу. Поддерживаемый файл из обычного окна
Проводника при таком drop копируется, а не забирается из исходной папки.
Фоновый запуск без первоначального показа:

```powershell
.\out\build\vs2022-x64\Release\Launchpad.exe --background
```

Окно останется скрытым. Нажмите `Win+Alt+Space`, чтобы показать его. Повторный
запуск exe также показывает существующий экземпляр.

Для отладки с завершением процесса после закрытия:

```powershell
.\out\build\vs2022-x64\Release\Launchpad.exe --exit-on-close
```

## Настройка автозапуска

Соберите Release, затем выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\install-autostart.ps1 `
  -Executable .\out\build\vs2022-x64\Release\Launchpad.exe
```

Скрипт добавляет только значение `WindowsLaunchpad` в
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` с аргументом
`--background`. Администратор не нужен. После входа используйте
`Win+Alt+Space`.

Отключение:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\remove-autostart.ps1
```

## Тесты

`LaunchpadTests` проверяет Unicode-поиск, фильтрацию расширений, постоянные
границы страниц и совместимость форматов раскладки, согласование сохранённой
раскладки, перемещение элементов, создание папок и порядок приложений внутри
них. Тесты включены стандартным `BUILD_TESTING=ON`.

```powershell
ctest --test-dir .\out\build\vs2022-x64 -C Release --output-on-failure
```

## Структура

```text
CMakeLists.txt

vcpkg.json
Applications/        единственный каталог показываемых приложений
LaunchpadLayout.store автоматически созданная раскладка пользователя
src/                 приложение, модель раскладки и manifest
src/assets/          многоразмерная Windows-иконка приложения
tests/               быстрые model-тесты
scripts/              установка, удаление, импорт, автозапуск и диагностика
docs/                 архитектура, UX, ограничения, источники, снимки
```

Раскладка хранится в компактном атомарно обновляемом файле формата
`WindowsLaunchpadLayout/2` рядом с `Applications/`. Записи `P` фиксируют
созданные пользователем границы страниц; старый формат версии 1 читается
автоматически. SQLite и сторонние runtime-библиотеки не требуются.

Иконка в `src/assets/launchpad.ico` извлечена из системного Launchpad на
локальном Mac для персональной Windows-сборки. Перед публичным распространением
проекта её следует заменить на собственный графический знак.
