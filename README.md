# Windows Launchpad

Нативный полноэкранный Launchpad для Windows 10/11, повторяющий интерфейс и
анимации классического Launchpad из macOS.

## Возможности

- страницы приложений с плавным свайпом;
- папки, перетаскивание и ручная сортировка;
- нечёткий поиск с поддержкой русского и английского языка;
- удаление ярлыков через режим покачивания;
- качественные системные иконки без повторной загрузки;
- поддержка экранов с высокой герцовкой и масштабированием;
- запуск без прав администратора.

## Установка

Скачайте `WindowsLaunchpad-0.3.0-Setup-x64.exe` со страницы
[Releases](https://github.com/w1lfpi/Launchpad/releases), запустите файл и
пройдите обычную установку. Права администратора и Visual C++ Runtime не
требуются.

Launchpad появится в меню «Пуск». Нажмите по нему правой кнопкой мыши и
выберите «Закрепить на панели задач». Автозапуск можно включить или отключить
в установщике.

Пока приложение не подписано цифровой подписью, Windows SmartScreen может
показать предупреждение. В таком случае нажмите «Подробнее» → «Выполнить в
любом случае».

## Добавление приложений

Добавляйте ярлыки `.lnk`, а не сами файлы `.exe`.

Нажмите `Ctrl+O` в Launchpad — откроется его отдельная папка приложений.
Переместите или скопируйте туда ярлык, и он автоматически появится в
Launchpad, даже если тот уже открыт. Нажатие `F5` не требуется.

Каталог хранится локально в
`%LOCALAPPDATA%\WindowsLaunchpad\Applications` и не занимает место на рабочем
столе. Ярлык также можно перетащить из Проводника прямо на нужное место в
Launchpad.

## Управление

| Действие | Управление |
|---|---|
| Запустить приложение | клик по иконке |
| Найти приложение | клик по строке поиска и ввод текста |
| Выделить весь запрос | `Ctrl+A` |
| Очистить поиск | `Esc` |
| Переключить страницу | свайп ЛКМ, колесо или `Page Up/Down` |
| Переместить приложение | удерживать и перетащить |
| Создать папку | перетащить приложение на другое |
| Добавить приложение в папку | перетащить его на папку |
| Переименовать папку | открыть папку и нажать на её название |
| Удалить ярлык | удерживать иконку и нажать крестик |
| Обновить список вручную | `F5` |
| Открыть `Launchpad Applications` | `Ctrl+O` |
| Показать или скрыть Launchpad | `Win+Alt+Space` |

Удаление из Launchpad убирает только ярлык. Он отправляется в Корзину, а если
она недоступна — в резервную папку Launchpad. Установленная программа остаётся
на компьютере.

## Удаление

Откройте «Параметры» → «Приложения» → «Установленные приложения», найдите
Windows Launchpad и нажмите «Удалить». Папка приложений и раскладка
сохраняются, чтобы не потеряться при переустановке.

## Сборка из исходников

Понадобятся Visual Studio с компонентом **Desktop development with C++**,
CMake, Ninja и Inno Setup 7.

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\build-installer.ps1
```

Готовый установщик появится в папке `dist`.
