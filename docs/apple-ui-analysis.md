# Разбор интерфейса macOS Launchpad

Основа этого разбора — присланный пользователем снимок 3840 × 2160,
официальные руководства Apple для классического Launchpad и Apple Human
Interface Guidelines. Точные размеры Launchpad Apple публично не
специфицирует, поэтому геометрия ниже измерена по референсу.

## Какая версия Launchpad является референсом

В macOS 26 Apple перенесла просмотр приложений в окно Apps внутри Spotlight:
там появились категории и режимы Grid/List. Это уже другой интерфейс.
Проект намеренно повторяет классический полноэкранный Launchpad из macOS 15 и
с присланного снимка, а не новый Spotlight Apps.

Официальное руководство Apple для Mac mini 2024 фиксирует поведение
классической версии:

- `Esc` или клик в любом месте, кроме иконки приложения, закрывает Launchpad;
- ввод имени фильтрует приложения;
- `Command+←/→` и горизонтальный свайп двумя пальцами меняют страницу;
- приложения перетаскиваются по сетке;
- перетаскивание одного приложения на другое создаёт папку.

Отдельная статья Apple уточняет, что при нескольких страницах можно нажимать
на нижние точки. Долгое нажатие переводит приложения в режим покачивания, а
удаление доступно только для приложений из App Store.

## Геометрия референса

- Полноэкранный transient overlay.
- Сетка: 7 столбцов × 5 строк.
- Около 35 приложений на страницу.
- Горизонтальные поля сетки: примерно 9–12% ширины экрана.
- Поисковое поле: около 15% ширины, небольшая высота и радиус 5–6 pt.
- Иконки визуально занимают около 55% ширины ячейки.
- Подписи одно­строчные, белые, без тяжёлой подложки.
- Точки страниц находятся отдельно под сеткой.

## Material

На референсе фон не является отдельной картинкой Launchpad:

1. сохраняются крупные цветовые массы пользовательских обоев;
2. мелкие детали теряются в сильном blur;
3. поверх добавлен тёмный нейтральный tint;
4. центр немного светлее краёв;
5. белые подписи и иконки сохраняют высокий контраст.

Apple HIG рекомендует материалы, blur и blending как способ сохранить контекст
содержимого под интерфейсом. Более тонкий материал показывает больше окружения,
а более толстый повышает читаемость. Для Launchpad нужен промежуточный вариант:
обои узнаваемы по цвету, но не конкурируют с иконками.

## Поиск

Согласно Apple HIG, search field содержит search glyph и placeholder, а
фильтрация должна происходить по вводимому термину. В референсе поле:

- постоянно доступно сверху;
- не требует отдельного режима экрана;
- визуально вторично по отношению к приложениям;
- использует полупрозрачную тёмную подложку и тонкую светлую рамку.

## Иконки

Apple HIG подчёркивает узнаваемость, ясный силуэт и согласованный визуальный вес.
Windows Launchpad не перерисовывает чужие логотипы и не использует Apple assets:
он запрашивает лучшие доступные Shell-иконки установленных Windows-приложений.
Иконки рисуются с собственной прозрачностью и пропорциями, без искусственной
цветной подложки, скругляющей маски и постоянной рамки.
Из-за различий Windows-иконок абсолютная унификация формы без подмены брендинга
невозможна.

## Страницы и жесты

- Одна неполная сетка остаётся одной страницей без декоративного индикатора.
- При переполнении появляются реальные дополнительные страницы; количество
  точек совпадает с их количеством.
- Активная точка яркая, остальные приглушены; точки являются кнопками
  навигации.
- Движение влево открывает следующую страницу, движение вправо — предыдущую;
  переход не зацикливается на краях.
- На Mac основной жест — два пальца на trackpad. В Windows сохранён
  горизонтальный touchpad-wheel, а для обычной мыши добавлен эквивалент:
  удерживать ЛКМ на пустом фоне и провести влево/вправо.

## Реализация в проекте

| Референс macOS | Windows Launchpad |
|---|---|
| Системный материал над обоями | snapshot монитора, downsample, 3 blur pass, dark tint |
| Vibrancy белого текста | DirectWrite, высокий контраст и opacity 94% |
| 7 × 5 | 7 × 5, 35 элементов |
| Компактный Search | ширина 17%, высота 32 DIP |
| Горизонтальные страницы | trackpad, ЛКМ-свайп по фону, точки, Ctrl+стрелки, edge-hover при переносе, сохранение скорости жеста и критически затухающий переход |
| Клик вне приложения закрывает overlay | клик по пустому месту скрывает/закрывает окно |
| Контролируемый набор приложений | отдельная папка `Applications/` |
| Системные app icons | `IShellItemImageFactory`, DPI-bucket от 256 px, preload, raw-alpha draw и D2D cache |
| Покачивание, ручной порядок и удаление | удержание 340 мс, drag-and-drop, крестик и постоянная раскладка |
| Папки | drop в центр иконки, preview 3 × 3, отдельный заголовок над широкой матовой панелью, адаптивная высота по числу рядов, перестановка детей и извлечение на корневую сетку |

## Выявленные отличия, которые ещё остаются

- Семантика крестика отличается от macOS: Windows Launchpad не запускает
  деинсталлятор, а перемещает подтверждённый управляемый ярлык или файл из
  `Applications/` в Корзину. Цель ярлыка при этом не затрагивается.
- Папки поддерживают первый уровень и извлечение иконки наружу; вложенные
  папки пока не реализованы.
- ЛКМ-свайп начинается только на пустом фоне, чтобы не конфликтовать с
  перетаскиванием иконок; текущая и соседняя страницы следуют за курсором.
