Проверены вручную:

- полноэкранное окно на текущем мониторе;
- загрузка настоящих иконок Windows Shell;
- чтение только управляемой папки `Applications/`;
- импорт ярлыков с исключением служебных пунктов и
  `Parallels Shared Applications`;
- отсутствие точек при одной странице;
- ровно две точки при временном наборе из 36 элементов;
- переход на вторую страницу через `Page Down`;
- переход на вторую страницу свайпом ЛКМ по пустому фону;
- завершение page-settle без перелёта не позднее примерно 1,10 с;
- скрытие прогретого экземпляра кликом по пустой подложке;
- размытая подложка из актуального содержимого монитора;
- фильтрация строкой `fire`;
- корректная отрисовка при 200% DPI;
- закрытие по `Esc`;
- предварительная загрузка иконок без постепенного появления;
- длительное удержание, покачивание и перемещение иконки;
- перенос на существующую страницу после удержания у края;
- создание новой страницы у правого края и сохранение её границы;
- создание папки drag-and-drop и добавление третьего приложения;
- сохранение папки в `LaunchpadLayout.store`;
- открытие папки и отрисовка её содержимого;
- отдельный заголовок над панелью, полное исчезновение корневого UI и
  адаптивная высота для папок на один и два ряда;
- перестановка двух приложений внутри открытой папки и сохранение порядка;
- извлечение приложения из папки на корневую сетку и на новую страницу;
- полный откат извлечения по `Esc` с неизменным SHA-256 файла раскладки;
- появление крестика в корне и внутри папки;
- встроенная тёмная панель подтверждения и отмена без системного окна;
- подтверждённое перемещение тестового ярлыка в Корзину при сохранности
  целевой установленной программы;
- Unicode-переименование папки и сохранение нового имени;
- остановка frame pump в скрытом состоянии.

Model-тесты дополнительно проверяют чтение старого
`WindowsLaunchpadLayout/1`, round-trip формата версии 2, нормализацию
ведущих/завершающих/соседних записей `P`, перенос на новую страницу и
устойчивый порядок приложений внутри папки, а также извлечение из папок
размером два и три элемента.

## Сбор диагностической информации

Из PowerShell в корне проекта:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\diagnose.ps1 `
  -Executable .\out\build\vs2022-x64\Release\Launchpad.exe
```

Скрипт ничего не меняет: он печатает версию ОС, каталоги меню «Пуск»,
количество доступных для импорта ярлыков, сведения об exe и состояние
автозапуска.

## Если окно не открывается

1. Запустите `Launchpad.exe` повторно: он отправит команду уже работающему
   фоновому экземпляру.
2. Проверьте процесс в Диспетчере задач и сочетание `Win+Alt+Space`.
3. Убедитесь, что обе папки меню «Пуск» доступны текущему пользователю.
4. Запустите `ctest` с `--output-on-failure`.
5. Удалите только каталог своей сборки `out\build\<preset>` и сконфигурируйте
   preset заново.
