# Ограничения

- Каталог строится только из `Applications/`. UWP/Store-приложение без обычного
  ярлыка нужно добавить вручную или импортировать отдельным скриптом.
- `sync-applications.ps1` применяет консервативный фильтр: исключает
  документацию, SDK-команды, установщики, административные оснастки и
  вспомогательные системные средства, дубли режимов запуска и прокси-ярлыки
  из `Parallels Shared Applications`. Редкое приложение с похожим служебным
  названием можно добавить вручную в `Applications/`.
- Некоторые старые ярлыки возвращают Shell-иконку небольшого размера; её
  качество при масштабировании определяется самим установленным приложением.
  Launchpad не увеличивает такой ресурс заранее, но запрашивает DPI-bucket
  минимум 256 px и выполняет только финальное пропорциональное масштабирование.
- Реализованы покачивание, drag-and-drop, постоянные страницы, ручной порядок,
  перестановка внутри папок, извлечение на корневую сетку и папки первого
  уровня. Вложенные папки и деинсталляция приложений Windows намеренно не
  поддерживаются.
- Крестик удаляет только подтверждённый объект из управляемой папки
  `Applications/` через Корзину или локальную резервную папку, если Корзина
  недоступна. Для ярлыков целевая программа остаётся установленной; для
  прямого `.exe` перемещается сам исполняемый файл.
- Drop поддерживаемого файла из Проводника или системной Корзины обновляет
  каталог автоматически. Изменения `Applications/`, сделанные другим способом,
  также обнаруживаются автоматически; `F5` остаётся ручным обновлением.
- Первоначальный запуск ждёт предварительной загрузки Shell-иконок до показа
  окна. На очень большом или медленном сетевом каталоге это увеличивает
  стартовую паузу, но исключает появление иконок по одной в видимой сетке.
- Плитки Direct2D пока не представлены отдельными элементами UI Automation.
- Фон — статический размытый снимок, сделанный в момент открытия. Он не
  обновляет движения окон под overlay до следующего открытия.
- Desktop Acrylic требует Windows 11 build 22621. На Windows 10 остаётся
  собственная screenshot/blur-подложка, поэтому интерфейс не становится
  непрозрачным.
- Глобальное сочетание `Win+Alt+Space` может быть занято другой программой.
  В этом случае фоновый процесс останется запущенным, но сочетание не сработает;
  повторный запуск `Launchpad.exe` всё равно покажет окно.
- Проект не заменяет меню «Пуск», не изменяет системные ярлыки и не требует
  прав администратора.
- Установщик создаёт корректный ярлык, но не закрепляет его молча: в Windows 11
  пользователь сам выбирает **Закрепить на панели задач** в меню «Пуск».
- Системная иконка Apple используется только в персональной локальной сборке;
  для публичного распространения нужен собственный знак.
